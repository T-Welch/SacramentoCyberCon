# FAQ

When and where is it?

Date and venue are still being finalized. Sign up above and we'll email you as soon as they're locked in.

How much will tickets cost?

We aim to keep it affordable, with discounted student tickets. Pricing will be announced with registration.

I've never given a talk. Can I still apply?

Absolutely. Tick "This would be my first talk" and we'll pair you with a mentor to help you prepare.

What happens to my info?

It's stored in a private spreadsheet only the organizers can access, used only to plan the con and contact you about it. We never sell or share it.

Is there a Code of Conduct?

Yes. The con follows the DC916 Code of Conduct.
